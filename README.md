# Homepage

A simple, clean personal homepage for showcasing mini-projects.

## Features

- Modern, responsive design that works on desktop and mobile devices
- Sections for:
  - About Me
  - Project showcase with card-based layout
  - Contact information
- Clean gradient header with purple theme
- Smooth hover animations on interactive elements

## Usage

Simply open `index.html` in a web browser to view the homepage.

To customize:
1. Edit `index.html` to update your personal information and projects
2. Modify `styles.css` to change colors, fonts, and layout
3. Replace placeholder links with your actual project URLs and contact information

## Development

To view the site locally, you can use any simple HTTP server:

```bash
# Python 3
python3 -m http.server 8080

# Node.js (with npx)
npx http-server
```

Then open `http://localhost:8080` in your browser.
